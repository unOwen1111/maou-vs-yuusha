# 魔王VS勇者

Python（tkinter）で作ったターン制バトルゲームです。勇者を操作して魔王と戦います。

## 遊び方

```
python Game2.py
```

画像ファイル（`battle_background.png` / `hero_win.png` / `demon_win.png`）と同じフォルダで実行してください。

## 勇者の技

| 技 | 効果 |
| --- | --- |
| ハイパースラッシュ | 10ダメージ・命中90% |
| ウルトラバースト | 30ダメージ・命中80% |
| スーパーヒール | HPを40回復 |
| ミラクルブースト | 次の攻撃が2倍 |

魔王は毎ターン、ヘルファイア・ダークスラッシュ・ダークドレイン・デモニックブーストの中からランダムに技を使います。HPはどちらも250です。
